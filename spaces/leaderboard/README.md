# LabCraft-Eval Leaderboard

Read-only leaderboard for the manifest-backed LabCraft-Eval Hugging Face
dataset snapshot. The app reads exported JSONL files and copied plots from:

<https://huggingface.co/datasets/jang1563/LabCraft-Eval>

It does not scrape GitHub Markdown pages or recompute benchmark scores.
